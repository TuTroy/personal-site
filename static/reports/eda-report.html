字段名类型说明
ticket_idstring工单唯一编号，格式 TKT-XXXXX
created_datedatetime工单创建时间，精确到分钟
resolved_datedatetime工单解决时间，未解决的为空
categoryenum (8)工单大类：Hardware / Software / Access&nbsp;Permissions / Network / Email&nbsp;Communication / Database / Cloud&nbsp;Infrastructure / Security
sub_categoryenum (42)细分类别，如 Account Lockout、Printer、VPN Issues、Malware 等
priorityenum (4)优先级：Critical / High / Medium / Low
statusenum (5)当前状态：Open → In Progress → Pending → Resolved → Closed
subjecttext工单标题，简要描述问题（英文）
descriptiontext工单详细描述，包含用户叙述、影响范围、紧急程度
resolutiontext解决方案描述，包含处理步骤和最终结果
product_servicestring涉及的产品或服务，如 MacBook Pro M3、Cisco AnyConnect、Slack 等
departmentenum (14)处理部门：IT / Finance / Engineering / HR / Marketing 等
satisfaction_ratingfloat (1-5)用户满意度评分，1 最低 5 最高
time_to_resolution_hoursfloat解决耗时（小时），未解决工单为空
text_lengthint工单描述文本长度（字符数）
